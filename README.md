# RescueNet SOS 

**An emergency response app with shake detection and smart connectivity features.**

## 📌 Features
-  **Shake Detection:** Automatically sends an SOS message to specified contacts via SMS when the device is shaken.
-  **Offline SOS:** Sends distress messages along with location and audio link to specified contacts even without an internet connection.
-  **Dijkstra’s Algorithm:** Finds the nearest emergency contacts efficiently (not implemented now).We can send message for selected contacts till now. 
-  **Audio Message:** Records a 10-second audio message and uploads it when connectivity is restored.

## 🛠️ Tech Stack
- **Language:** Java
- **UI:** XML
- **Backend:** Firebase
- **Database:** Firestore

## 🚀 Installation & Setup
### Steps
1. **Clone the Repository**
   ```sh
   git clone https://github.com/Sumit-22/sos_audio.git
   ```
2. **Open in Android Studio**
3. **Configure Firebase**
   - Add `google-services.json` to the `app/` directory.
4. **Run the App**
   - Build and install the app on an emulator or physical device.
